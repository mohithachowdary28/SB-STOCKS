# 📈 SB Stocks - Stock Trading App

SB Stocks is a basic stock trading web application designed for learning and practicing stock trading using virtual money.

## 🚀 Features

- User Registration
- User Login
- Dashboard
- View Available Stocks
- View Stock Prices
- Basic Portfolio
- Basic Paper Trading
- Stock API

## 🛠️ Technologies Used

### Frontend
- HTML
- CSS
- JavaScript
- React.js

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Tools
- Visual Studio Code
- Git
- GitHub
- npm

Project Objective

The objective of SB Stocks is to provide a simple educational paper-trading platform where users can learn the basics of stock trading without using real money.
